# Image assets

Real documentary-style photography for frontend testing.

## Source
Free Unsplash License photos downloaded for development/demo use only.
Replace with approved, licensed organisational photography before production.

## Enable / disable
Controlled by `IMAGES_AVAILABLE` in `components/shared/AppImage.tsx`.
Currently set to `true`.

## Folders
- `/images` — homepage hero / about / testimonial
- `/images/about` — About Us page
- `/images/work` — focus areas
- `/images/projects` — project cards + galleries
- `/images/news` — news articles
- `/images/team` — team portraits
- `/images/campaigns` — campaign cards
- `/images/events` — events + galleries
- `/images/impact` — impact stories
- `/images/media` — media centre gallery
